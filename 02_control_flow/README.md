# Control Flow in C

This folder contains a structured learning path for **Control Flow** in the C programming language.

Control flow determines **the order in which statements are executed** during program execution. It allows a program to make decisions, repeat operations, and organize execution paths based on conditions or events.

The examples in this folder progress from basic decision-making to common programming patterns used in embedded firmware development.

---

## Learning Objectives

After completing this folder, you will understand how to:

- Make decisions using conditional statements.
- Select execution paths using `switch`.
- Repeat tasks using loops.
- Control loop execution using `break` and `continue`.
- Build finite state machines.
- Implement guard clauses and early returns.
- Write clean and maintainable control logic.
- Apply common control-flow patterns used in embedded systems.
